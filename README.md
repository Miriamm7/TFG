# Autoría
Miriam Montero Mena
# Área
Trabajo Social orientado a menores
# Tema
Uso de las redes sociales y bienestar en adolescentes de un instituto
# Población
Adolescentes y padres de familia
# Pregunta y objetivos
¿Afecta el uso de las redes sociales en la relación parental? ¿Afecta el uso de las redes sociales a la salud mental de los menores? ¿Se puede determinar si las redes sociales propician estas conductas o solo son una vía de escape de un problema existente?
Objetivo general: Verificar si existe una constancia real de que el uso de las redes sociales suponen un cambio en la conducta familiar-afectiva.
Objetivos específicos: Recopilar datos de las horas de uso de internet tanto en padres como adolescentes. Comprobar la hipótesis de que los adolescentes que usan más tiempo las redes tienen una peor relación con sus padres. Comprobar si existe una relación redes sociales-estado mental de los adolescentes.
